# INVARIANT — справочник по физике

Единый сайт для всех учеников: пройденные темы, теория, домашние задания и ответы
для самопроверки. Ученик открывает одну ссылку и выбирает тему.

## Как это устроено

```
темы/<раздел>/<тема>.md   ← ты пишешь только это
скрипты/собрать.py        ← собирает сайт
docs/                     ← готовый сайт (его публикует GitHub Pages)
docs/assets/img/          ← логотип и баннер
архив/                    ← старые ДЗ в прежнем формате
```

Правишь `.md`, запускаешь сборку, отправляешь изменения — сайт обновился.

## Работа через Claude

В проекте лежит настройка, чтобы новая сессия сразу понимала, что делать:

| Файл | Что даёт |
|---|---|
| `CLAUDE.md` | Подхватывается **автоматически** в каждой сессии: формат тем, синтаксис формул, твои обозначения, правила. Ничего вызывать не нужно. |
| `.claude/skills/new-topic/` | Команда `/new-topic` — пошаговый разбор материалов занятия. |
| `.claude/agents/physics-topic.md` | Агент `physics-topic` для делегирования, когда тем сразу несколько. |

Обычный сценарий: открываешь новую сессию в этой папке, кидаешь фото конспекта
и ссылку на сборник задач, пишешь «сделай тему про ускорение». Дальше он сам.

Главное правило, которое там прописано: **задачи берутся только из твоих
источников**. Придуманные нейросетью условия дают неверные ответы, и ученик
находит это уже после сдачи.

## Добавить тему после занятия

1. Скопируй `шаблон-темы.md` в `темы/<раздел>/<название>.md`.
2. Заполни: теория, задачи, ответы.
3. Пересобери и опубликуй:

```bash
cd ~/Desktop/"Дз физика"
python3 скрипты/собрать.py
git add -A && git commit -m "Тема: средняя скорость" && git push
```

Через минуту тема появится на сайте. Ссылку на конкретную тему можно скинуть
отдельно — у каждой свой адрес.

Посмотреть, что получилось, до публикации: открой `docs/index.html` двойным кликом.

## Формат файла темы

Шапка между `---` — служебная:

```yaml
---
тема: Равномерное движение и средняя скорость   # заголовок на сайте
раздел: Кинематика                              # группа в оглавлении
порядок: 10        # чем меньше, тем выше в списке раздела
дата: 2026-07-25
кратко: Одна строка-описание для карточки на главной.
---
```

Класс нигде не указывается — один и тот же материал уходит и в 9, и в 10, и в 11.

Дальше — два раздела верхнего уровня.

### `## Теория`

Обычный markdown: `###` подзаголовки, `**жирный**`, списки, `> вынос` для правил
и предупреждений.

### `## Задачи`

Задача — номер жирным, следующей строкой ответ через `>`:

```markdown
**1.** Тело прошло 5,4 км за 6 мин. Найдите скорость.
> v = 15 м/с = 54 км/ч.
```

Ответы пишутся рядом с задачей — так удобно вбивать из сборника.
На сайте они автоматически уезжают вниз, под кнопку «Ответы».

`### Часть 1. …` внутри задач разбивает их на группы.

## Формулы

Пишутся между `$…$` в строке или `$$…$$` отдельным блоком. Поддерживается то,
что нужно школьной физике:

| Запись | Результат |
|---|---|
| `\frac{s}{t}` | дробь |
| `v_{ср}`, `x^{2}` | индекс, степень |
| `\sqrt{2gh}` | корень |
| `\vec{v}` | вектор со стрелкой |
| `\cdot \approx \leq \Delta \pi \omega` | символы |
| `\text{км/ч}` | обычный текст внутри формулы |

Пример:

```markdown
$$v_{ср} = \frac{s_1 + s_2}{t_1 + t_2}$$
```

## Публикация на GitHub Pages (один раз)

1. Заведи бесплатный аккаунт на github.com.
2. Создай пустой репозиторий, например `fizika` — **публичный** (для Pages на
   бесплатном тарифе нужен именно публичный).
3. В терминале, из папки проекта:

```bash
cd ~/Desktop/"Дз физика"
git config user.name "Твоё имя"
git config user.email "daniilstolarenko.1008@gmail.com"
git add -A
git commit -m "Справочник по физике"
git branch -M main
git remote add origin https://github.com/ТВОЙ-ЛОГИН/fizika.git
git push -u origin main
```

4. На GitHub: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/docs`. Сохрани.
5. Через 1–2 минуты сайт будет по адресу
   `https://ТВОЙ-ЛОГИН.github.io/fizika/` — эту ссылку и даёшь ученикам.

Дальше каждое обновление — три команды из раздела «Добавить тему».

## Логотип

Лежит в `docs/assets/img/`:

| Файл | Где виден | Размер |
|---|---|---|
| `logo-mark.png` | шапка, обложка главной, подпись внизу, иконка вкладки и на «Домой» | 256×256 |

Обложка на главной собрана вёрсткой — логотип, название и подпись «Физика» на
фирменном тёмно-синем. Готовый баннер для неё не используется: на нём написано
«Physics & Mathematics», а сборник только по физике. Сами файлы
(`banner.jpg`, `banner-sm.jpg`) остались в папке — если понадобятся, скажи.

Оригиналы (`INVARIANT banner v3`, `Лого инвариант`) лежат в корне проекта.
Если поменяешь логотип, замени `logo-mark.png` квадратной картинкой —
остальное подстроится само.

Подпись **INVARIANT** стоит внизу каждой темы и остаётся при печати, так что
на распечатанном ДЗ видно, чей это материал.

## Что ещё умеет сайт

- **Поиск** по названиям и тексту тем — в боковой панели, горячая клавиша `/`.
- **Светлое и тёмное оформление** — кнопка в шапке, выбор запоминается.
- **Печать**: кнопка «Распечатать» внизу темы даёт чистый лист с задачами,
  ответы уходят на отдельную страницу. Из браузера так же сохраняется в PDF.
- **Работает с телефона**, оглавление прячется в меню.
- Шрифты лежат внутри сайта — никаких обращений к внешним сервисам.
