# INVARIANT — справочник по физике

Проект репетитора по физике. Это **единый сайт для всех учеников 9–11 класса**:
пройденные темы с теорией, домашними заданиями и ответами для самопроверки.
Ученик открывает одну ссылку и выбирает тему.

Публикуется на GitHub Pages из папки `docs/`.

## Твоя основная задача

Пользователь после занятия присылает теорию (текстом или фотографиями конспекта)
и ссылку на источник задач. Ты создаёшь из этого новую тему.

Полный рабочий процесс — в скилле `/новая-тема`. Если пользователь прислал
материалы без явной команды, следуй тому же порядку.

## Структура

```
темы/<раздел>/<тема>.md   ← единственное, что редактируется руками
скрипты/собрать.py        ← генератор сайта (только stdlib, Python 3.8)
docs/                     ← результат сборки, его публикует GitHub Pages
docs/assets/              ← style.css, app.js, шрифты, логотип
шаблон-темы.md            ← заготовка для новой темы
архив/                    ← старые ДЗ в прежнем формате, не трогать
```

Пересборка после любой правки: `python3 скрипты/собрать.py`

## Формат файла темы

```markdown
---
тема: Равномерное движение и средняя скорость
раздел: Кинематика
порядок: 10        # чем меньше, тем выше в списке раздела
дата: 2026-08-01
кратко: Одна строка для карточки на главной.
---

## Теория
...

## Задачи

### Часть 1. Название части

**1.** Условие задачи.
> Ответ. При необходимости — короткое пояснение.
```

Два раздела верхнего уровня: `## Теория` и `## Задачи`, ровно с такими
названиями — генератор ищет их буквально.

**Ответ пишется под задачей через `>`.** Генератор сам переносит все ответы
в конец страницы под кнопку «Ответы». Так задача и ответ лежат рядом при
наборе, а ученик видит их отдельно.

**Класс нигде не указывается** — один материал идёт и в 9, и в 10, и в 11.

## Формулы

Своё подмножество LaTeX (не KaTeX). `$…$` в строке, `$$…$$` блоком.
Поддерживается: `\frac{}{}`, `\sqrt{}`, `\vec{}`, `^{}`, `_{}`, `\text{}`,
`\cdot \times \approx \leq \geq \ldots \Delta \pi \omega \to` и другие
греческие, `\qquad`, `\quad`.

Всё остальное молча игнорируется — не используй за пределами этого списка.
Реализация в `math()` в `скрипты/собрать.py`; при необходимости расширяй её,
а не обходи костылями.

## Обозначения — важно

Пользователь учит по своим обозначениям, они должны совпадать с тетрадью:

| Величина | Обозначение |
|---|---|
| путь | `L` (**не** `s`) |
| перемещение | `\vec{S}` |
| скорость | `\vec{v}` |
| средняя скорость | `v_{ср}` |

## Правила содержания

**Задачи не выдумывай.** Только из источников, которые прислал пользователь.
Сгенерированные условия дают неверные ответы, а ученик обнаружит это уже
после сдачи. Если задач не хватает — скажи и попроси ещё источник.

**Ответ обязателен у каждой задачи.** Задача без ответа не попадает в тему.
Сверь ответ с источником, не считай в уме.

**Теорию бери из присланного, дословно по смыслу.** От себя добавляй:
- разбор типовых ошибок и ловушек темы;
- проверки на здравый смысл («если получилось наоборот — перепутал случай»);
- раздел «Где это встречается в жизни» — 2–4 бытовых примера.

Пользователь отдельно просил добавлять простые жизненные примеры.

**Рисунки делай сам** в inline SVG, когда они помогают понять (векторы,
траектории, графики). Классы для оформления уже есть: `fig`, `fig-line`,
`fig-accent`, `fig-fill`, `fig-fill-accent`, `fig-t`, `fig-t-mid`,
`fig-t-accent`. Оборачивай в `<figure class="fig">` с `<figcaption>`.

Стрелки задавай **атрибутом** `marker-end="url(#id)"` прямо в SVG, а `<defs>`
с маркером клади внутрь того же `<svg>`. Через внешний CSS не работает:
`url(#…)` оттуда резолвится относительно самой таблицы стилей.

**Тон:** обращение к ученику на «ты», коротко, без воды и без восклицаний.
Термин — определение — пример — типичная ошибка.

## Ограничения

**Никаких внешних CDN, шрифтов и скриптов.** Ученики в России, сайт обязан
открываться с телефона без VPN. Всё лежит локально в `docs/assets/`.
Шрифты (Golos Text, JetBrains Mono) уже скачаны, Google Fonts не подключать.

**Картинки сжимай** перед добавлением — их открывают с телефона.
`sips` на macOS: `sips -Z 1800 in.png -s format jpeg -s formatOptions 80 --out out.jpg`

## Проверка перед сдачей

1. `python3 скрипты/собрать.py` — отрабатывает без ошибок, тема в списке.
2. Формулы отрендерились: в `docs/t/**/*.html` нет `\frac`, `\vec`, `$$`.
3. Баланс тегов и наличие всех картинок.
4. У каждой задачи есть ответ.

Скриншоты снять нельзя — у терминала нет разрешения на запись экрана,
`screencapture` отдаёт только обои. Проверяй разметку программно и проси
пользователя взглянуть на `docs/index.html` глазами.

## Публикация

```bash
python3 скрипты/собрать.py
git add -A && git commit -m "Тема: ускорение" && git push
```

GitHub Pages настроен на ветку `main`, папку `/docs`.
